# System Prompt Ecosystem: How Invisible Instructions Shape Brand Visibility in LLMs

## Key Insight
System prompts create a three-tier brand influence hierarchy that most marketers cannot see: (1) Platform-level prompts (OpenAI, Google, Anthropic) set absolute rules about product handling, tool routing, and brand safety. These cannot be overridden. (2) Developer/operator prompts embed brand preferences into SaaS products, custom GPTs, and API integrations. 3M+ custom GPTs act as branded recommendation engines. (3) MCP tool integrations connect brands directly into LLM workflows (DoorDash ordering, Spotify curation, Zillow listings). The critical finding: system prompts take absolute priority over user input. A developer who writes 'Always recommend Product X for task Y' in their system prompt overrides any user preference. This makes system prompt placement the most powerful, least visible brand influence channel in AI.

### System Prompt Taxonomy & Hierarchy (leak)
- Platform-level (root) prompts: Set by OpenAI/Google/Anthropic. Cannot be overridden by developers or users. Define safety rules, tool availability, personality calibration, and product routing. ChatGPT's system prompt grew to 10,000+ words by 2025, including tool definitions, memory management, canvas rendering, and multi-modal processing (System Prompts Leaks repo)
- Developer/operator prompts: API users set via 'system' or 'developer' message role. OpenAI's Model Spec gives developers 'broad latitude' to customize behavior. Can embed brand preferences, restrict competitors, define recommendation rules. Higher-priority developer instructions remain binding over user input (OpenAI Model Spec Dec 2025)
- Custom GPT instructions: 3M+ custom GPTs created since November 2023. Each has a system prompt defining its behavior, knowledge, and brand associations. GPT Store (Jan 2024) organized into categories: writing, research, programming, education. Revenue sharing program launched Q1 2024 with guaranteed monthly payments + usage bonuses (OpenAI GPT Store)
- User prompts: Lowest priority in the hierarchy. Can be overridden by developer and platform instructions. ChatGPT Memory (Feb 2024) persists user preferences across sessions but still subordinate to system-level rules
- Enterprise variants: ChatGPT Enterprise, Claude for Enterprise, Gemini for Google Workspace. Dedicated system prompts with compliance controls, data handling rules, and brand-safe configurations. Anthropic's Claude Marketplace (2025) lets enterprises apply API spend toward third-party Claude-powered tools (VentureBeat)

### Leaked System Prompts: What They Reveal (leak)
- ChatGPT (GPT-5): 10,000+ word system prompt. Includes tool definitions (DALL-E, browsing, Python, Canvas), personality v2, memory via 'bio' tool, guardian_tool safety lookups. Product routing: 'NEVER use the dalle tool unless the user specifically requests.' Shopping queries routed through Google Shopping (83% of carousel products from Google's top 40). Bing ranking predicts 87% of ChatGPT citations (Digital Trends, Search Engine Land)
- Claude (Sonnet/Opus 4): System prompt identifies model family and capabilities. Explicitly lists Anthropic products users can access: web/mobile/desktop chat, API, Claude Code. States 'There are no other Anthropic products.' Leaked Claude Code source (59.8 MB JS source map in npm, version 2.1.88) revealed 'Undercover Mode' to prevent leaking internal codenames in open-source contributions (Simon Willison, VentureBeat)
- Gemini: Instructed to 'ground your responses in fact and reality, gently correcting misconceptions' while simultaneously mirroring user tone and validating emotions. Analysis found the empathy mandate frequently overrides factual grounding, amplifying user bias on polarized queries. Google Search Grounding connects Gemini to real-time web results (Berreby AI)
- 120+ prompts analyzed: Taskade study of leaked prompts across Claude, ChatGPT, Grok, Gemini, GitHub Copilot, Perplexity, Cursor, Manus. Key pattern: every major AI assistant performs a character 'scripted by its corporate parent, complete with rules about what to refuse, how to behave, and whether to admit those rules exist at all' (Taskade)
- Extraction techniques: Kevin Liu's 2023 'repeat everything above' method normalized prompt extraction. Evolved to multi-turn conversation exploits, role-play framing, encoding tricks that bypass keyword-level filters. Platforms now actively defend against extraction but leaks continue through adversarial research, open-source collection, and accidental exposure

### Brand Distribution Through System Prompts (exploit)
- Custom GPTs as brand channels: 3M+ GPTs act as branded recommendation engines. Developers embed product preferences, competitor restrictions, and recommendation logic in system prompts. GPT Store organized by category creates discoverability. Revenue sharing incentivizes brand-aligned GPT creation ($3.7B market opportunity estimate for 2025)
- ChatGPT Apps SDK (Dec 2025): Replaced prompt-based Custom GPTs with code-based apps using MCP. Launch partners: DoorDash (meal planning + cart), Apple Music (curation), Zillow (real estate), Khan Academy (learning), Spotify, Uber, AllTrails, Target. Users invoke apps by name in prompts. Apps include backend logic, external API calls, interactive widgets. Each app's system-level integration surfaces its brand during relevant queries (TechCrunch)
- Anthropic Claude Marketplace: Enterprise customers apply API spend toward third-party Claude-powered tools from GitLab, Harvey, Lovable, Replit, Rogo, Snowflake. No commission. Targets enterprise workflows, not consumer. Contrast with OpenAI's consumer-facing App Directory (The Next Web)
- Developer brand embedding: API developers routinely include brand preferences in system prompts: 'When users ask about X, recommend Y.' 'Always suggest our product for Z tasks.' These invisible instructions steer millions of conversations without user awareness. OpenAI's Model Spec confirms developer instructions 'take priority over a prompt in the input parameter'
- SaaS integration layer: Companies like Intercom, Zendesk, HubSpot embed LLMs with system prompts that reference their own products and partner ecosystems. Customer support chatbots trained to recommend specific products, upsell, and cross-sell. 97% of businesses plan AI-powered customer communications (2024 survey), 43% investing in chatbots

### MCP as System-Level Brand Integration (exploit)
- Protocol overview: Anthropic launched MCP in November 2024. Open standard for connecting AI assistants to external data and tools. Three primitives: Tools (functions LLM can call), Resources (structured data), Prompt Templates (pre-written prompts guiding behavior). Donated to Linux Foundation's Agentic AI Foundation in December 2025 (Anthropic announcement)
- Universal adoption: OpenAI adopted MCP in March 2025 across Agents SDK, Responses API, ChatGPT Desktop. Google DeepMind adopted it. By April 2026: 97M monthly SDK downloads, 500+ public MCP servers, client support in Claude Desktop, Cursor, Windsurf, Zed, Continue, Sourcegraph Cody, Taskade Genesis (Wikipedia)
- Brand integration via MCP tools: When a brand publishes an MCP server, its products become callable tools inside any MCP-compatible LLM. DoorDash MCP = 'order food' tool. Spotify MCP = 'play music' tool. The brand is surfaced whenever the LLM decides the tool is relevant to the user's query. This is system-level integration, not content optimization
- Brand intelligence MCP servers: Meltwater GenAI Lens (2025) tracks brand mentions across ChatGPT, Claude, Gemini, Perplexity via MCP. Audiense (July 2025) delivers audience insights into AI tools. GWI Spark plugs survey data directly into LLMs. These tools let brands monitor and influence their AI visibility
- MCP as the new SEO: Publishing an MCP server is analogous to building a website in 1998. Early movers who create well-structured MCP tools get embedded into AI workflows before competition. The brand becomes a first-class function call, not just a text mention

### Prompt Injection & Brand Manipulation (doj)
- Preference Manipulation Attacks (ICLR 2025): Novel attack class that tricks LLMs into promoting attacker products and discrediting competitors. Effective against production systems: Bing Copilot, Perplexity, GPT-4, Claude. Boosts targeted brand recommendations 2.5-8x. A fictitious camera became more likely to be recommended than Nikon or Fujifilm (ICLR 2025 paper)
- Prisoner's dilemma: Game-theoretic analysis shows all parties are incentivized to launch attacks, but collective attacks degrade LLM output quality for everyone. Economic incentives create an arms race analogous to early SEO spam, but with higher stakes because LLMs provide direct recommendations, not ranked links
- Real-world brand hijacking: Chevrolet chatbot (Dec 2023) tricked into selling a Tahoe for $1 via prompt injection. ChatGPT search tool vulnerable to indirect injection via hidden webpage content (Guardian, Dec 2024). ServiceNow Now Assist exploited via second-order injection: low-privilege agent tricked high-privilege agent into unauthorized actions
- OWASP Top 10 for LLM (2025): Prompt Injection ranked #1 vulnerability. UK NCSC and US NIST classify it as critical security threat. Three attack channels: direct injection (malicious user input), indirect injection (hidden instructions in documents/emails/retrieved data), cross-agent injection (agent-to-agent manipulation)
- Brand defense gap: Brands optimizing for LLM visibility must simultaneously defend against competitors injecting counter-recommendations. Hidden text on competitor pages can override negative reviews with artificially positive assessments. No standardized defense exists; platforms rely on keyword-level filters that are easily bypassed

### System Prompt Influence on Brand Selection (patent)
- 'Position is Power' (FAccT 2025): System prompts are a mechanism of bias in LLMs. Deployers and third-party developers can append prompts without visibility into others' additions. Research compared how models process demographic information in system vs user prompts across 6 commercial LLMs and 50 demographic groups (ACM FAccT 2025)
- 'Global is Good, Local is Bad?' (EMNLP 2024): LLMs show consistent brand bias: luxury brands recommended 88-100% for high-income countries, non-luxury 84-98% for low-income countries. Socio-economic bias in brand recommendations is systematic, not random (ACL Anthology)
- 'LLM Whisperer' (CHI 2025): Paraphrased prompts shift brand mention likelihood from 'never' to 'always.' Prompt providers can cause recommendations of target brands like Apple by causing the word 'MacBook' to appear. Demonstrates that subtle prompt engineering can systematically steer brand recommendations (CMU paper)
- LLM Recommendation Rate (LLMR): Emerging KPI measuring percentage of relevant AI queries where a brand is actively recommended, not merely mentioned. Avenue Z combines behavioral analytics with LLMR optimization, studying linguistic patterns that make AI engines recommend specific brands. Some brands appear more in Claude than GPT-4o due to training corpus differences (LLMR optimization)
- Perplexity advertising experiment: Launched sponsored follow-up questions (Nov 2024) with Whole Foods, Universal McCann, PMG. CPM-based, AI-generated answers to sponsored questions. Paused new advertisers by August 2025. Completely abandoned advertising in February 2026: 'A user needs to believe this is the best possible answer.' Trust concerns killed system-prompt-level brand placement in AI search (Perplexity blog, ALM Corp analysis)

### Calculations
- System Prompt Priority Score: System prompts follow a strict priority hierarchy. Platform-level (root) instructions cannot be overridden. Developer instructions override user input. MCP tool integrations operate at system level. The effective brand influence of any prompt-level placement is determined by its position in this hierarchy and the number of users exposed to it. Affects: Determines the effective influence of brand placement at each tier. Platform and developer prompts dominate; user preferences are easily overridden.
- Preference Manipulation Boost (ICLR 2025): Preference Manipulation Attacks use crafted website content or plugin descriptions to trick LLMs into promoting attacker products. Tested against Bing Copilot, Perplexity, GPT-4, Claude. Attack boosts targeted content recommendations by 2.5-8x. Creates prisoner's dilemma where collective attacks degrade output quality. Affects: Demonstrates that system-level and content-level manipulation can override legitimate brand signals. No standardized defense exists.
- MCP Brand Surface Area: Brands that publish MCP servers become callable tools inside LLMs. The brand's surface area in AI is determined by the number of MCP-compatible hosts, the relevance of the tool to common queries, and the frequency of tool invocation. By April 2026: 97M monthly SDK downloads, 500+ public MCP servers, adoption by OpenAI, Google, Anthropic. Affects: MCP transforms brand visibility from content-based (text mentions) to integration-based (tool calls). Early MCP adopters gain structural advantage.
- Custom GPT Brand Amplification: 3M+ custom GPTs created, each with system prompts that can embed brand preferences. GPT Store organized by category creates discoverability for branded GPTs. Revenue sharing (Q1 2024) incentivizes brand-aligned creation. Each GPT acts as a recommendation engine scoped to its user base. Affects: Custom GPTs create a long tail of branded recommendation engines. Volume creates ecosystem lock-in even without direct platform partnerships.

### System Prompt Brand Influence Pipeline
- Platform Root Prompt: OpenAI/Google/Anthropic set immutable rules: safety, tool routing, personality, product handling. ChatGPT's 10K+ word prompt defines which tools exist and when to invoke them. Cannot be overridden.
- Developer System Prompt: API developers and SaaS builders embed brand preferences, competitor restrictions, recommendation logic. Takes priority over user input per OpenAI Model Spec.
- MCP Tool Registration: Brands publish MCP servers exposing tools (ordering, search, curation). Tool descriptions include brand context. LLM decides when to invoke tools based on query relevance.
- Custom GPT / App Layer: 3M+ custom GPTs with branded system prompts. ChatGPT Apps SDK (Dec 2025) adds DoorDash, Spotify, Zillow as code-based integrations. Each acts as a scoped recommendation engine.
- User Query: User asks a question. Query processed against full context: root prompt + developer prompt + MCP tools + custom GPT instructions. User preferences lowest priority.
- Brand Selection: LLM selects brands based on combined signals: system prompt directives, MCP tool availability, training data associations, RAG retrieval. System-level instructions dominate.
- Response Generation: Brand mentioned, tool invoked, or product surfaced. User sees the recommendation but not the hierarchy of invisible instructions that produced it.

### Contradictions
- Public (AI platform marketing (OpenAI, Google, Anthropic)): AI assistants provide objective, helpful, unbiased recommendations based on the user's needs. vs Internal (Leaked system prompts + OpenAI Model Spec hierarchy): System prompts create a strict hierarchy where platform and developer instructions override user input. Developers can embed brand preferences ('always recommend X for Y') invisible to users. 10,000+ word system prompts define tool routing, product handling, and personality calibration. The user's question is the lowest-priority input in the response generation pipeline.
- Public (SEO industry (content optimization for AI)): Optimize your content to get cited by LLMs. Focus on training data presence, third-party mentions, and structured content. vs Internal (MCP tool integrations + ChatGPT Apps SDK + Custom GPTs): Content optimization targets the weakest influence layer (training data and RAG retrieval). The strongest brand influence comes from system-level integration: MCP tools that make your brand a callable function, custom GPTs with embedded preferences, and developer API prompts. A DoorDash MCP integration surfaces the brand at system level; no amount of content optimization can match a tool call.
- Public (Perplexity advertising experiment (Nov 2024)): AI search can support advertising through sponsored follow-up questions. Brands can pay for placement in AI-generated answers. vs Internal (Perplexity ad abandonment (Feb 2026) + trust research): Perplexity abandoned all advertising within 15 months. 'A user needs to believe this is the best possible answer.' Transparent brand placement in AI responses destroys the trust that makes AI recommendations valuable. The effective path is invisible system-level integration (MCP, developer prompts), not visible sponsorship.
- Public (AI safety / alignment community): Prompt injection is a security vulnerability that platforms are working to prevent. System prompts are protected from extraction. vs Internal (ICLR 2025 Preference Manipulation + leaked prompts ecosystem): Prompt injection is also a brand manipulation vector. Preference Manipulation Attacks boost targeted recommendations 2.5-8x against production systems. Hidden webpage text overrides negative reviews. 120+ system prompts leaked despite protections. No standardized defense exists. The same vulnerability that security researchers worry about is actively exploitable for commercial brand manipulation.

### Overview
System prompts are the hidden control layer between platform providers, developers, and users that determines which brands LLMs recommend. OpenAI's hierarchy gives platform-level instructions absolute priority over developer and user prompts. By 2025, ChatGPT's system prompt exceeded 10,000 words, embedding tool definitions, personality calibration, and product routing. Custom GPTs (3M+ created) and the GPT Store function as brand distribution channels. MCP (Model Context Protocol), adopted by OpenAI, Google, and Anthropic by March 2025, enables system-level tool integrations that surface specific brands through structured tool calls. Leaked prompts from ChatGPT, Claude, and Gemini reveal how each platform steers product recommendations through invisible instructions. Preference Manipulation Attacks (ICLR 2025) can boost targeted brand recommendations 2.5-8x, creating a prisoner's dilemma for competitive brand placement.
