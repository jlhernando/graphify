# Sitelinks: Google's Navigational Sub-Link System

## Key Insight
Sitelinks are not curated by webmasters. Google's system automatically identifies candidate internal links, scores them by visual location on the page (patent US9053177), click-through frequency, and anchor text relevance. Tangram assembles sitelinks as a discrete SERP feature, meaning they are composed separately from the organic blue links and inserted into the result layout by SuperRoot. Links positioned in the primary navigation area (top of page, above the fold) receive higher sitelink scores than footer or sidebar links. Click data from NavBoost further refines which internal pages appear as sitelinks, creating a feedback loop where popular pages become more visible sitelinks.

### API Leak Evidence (leak)
- Tangram - SERP feature assembly system that composes sitelinks as a discrete feature block. Sitelinks are not part of the core organic ranking output but are assembled post-ranking as a navigational enhancement by Tangram's feature compositor
- SuperRoot - Orchestration layer that decides which SERP features appear for a given query. For navigational/brand queries, SuperRoot triggers sitelink generation. SuperRoot coordinates between Tangram, organic results, and other feature backends
- NavBoost click signals - Click-through data on internal pages feeds sitelink selection. Pages with high goodClicks and low badClicks from the main site are promoted as sitelink candidates. The chromeInTotal and directFrac signals at the site level correlate with sitelink eligibility
- Query classification - Sitelinks trigger primarily for navigational intent queries. The query classifier must identify the query as brand/navigational before SuperRoot activates the sitelink feature. Informational queries rarely receive sitelinks
- SiteLinkIn (QualityNsrNsrData module) - Average value of incoming links to the site. Higher incoming link value correlates with stronger sitelink eligibility and more prominent sitelink display
- siteLinkDistance (QualityNsrNsrData module) - Average link click distance from the homepage, measuring site depth. Lower distance values indicate a flatter site architecture, which improves sitelink candidate discovery

### Patent Evidence (patent)
- Visual location scoring (Patent US9053177, Minkoo Seo, Google): Scores hyperlinks based on their visual location within the rendered page. Links in the primary navigation (top, above-fold) receive higher scores than footer or sidebar links. The system renders the page DOM to determine visual coordinates, then maps each hyperlink to a scoring zone. This means hidden, CSS-displaced, or below-fold links are deprioritized as sitelink candidates
- Hyperlink object identification (US9053177): The patent identifies a plurality of hyperlinks within the document, each as a hyperlink object with associated visual properties. The system distinguishes navigation links, content links, and utility links by their DOM position and rendering characteristics
- Score-based sitelink selection (US9053177): Final sitelink set selected by ranking all candidate hyperlinks by their composite score (visual location weight + anchor relevance + click popularity). Top-N scoring links become the displayed sitelinks, typically 4-6 for full sitelinks or 2-4 for compact format

### How Sitelinks Affect Your SEO (exploit)
- Place key pages in primary navigation: Patent US9053177 confirms visual location matters. Links in your top navigation bar, above the fold, score higher for sitelink candidacy. Ensure your most important pages (products, services, about, contact) are in the main nav, not buried in footers or sidebars
- Use clear, descriptive anchor text: Sitelink labels are derived from anchor text and page titles. Vague anchors like 'Click here' or 'Learn more' reduce sitelink quality. Use specific anchors like 'Pricing Plans' or 'Customer Support' that match user search intent
- Build a flat, crawlable site structure: Google needs to discover and render internal pages to score them as sitelink candidates. A shallow hierarchy (homepage to key pages in 1-2 clicks) maximizes the pool of eligible pages. Deep, orphaned, or JavaScript-only links are less likely to become sitelinks
- Drive branded search volume: Sitelinks trigger primarily for navigational queries. The more users search for your brand name, the stronger the signal that sitelinks are needed. Brand awareness campaigns indirectly improve sitelink presence
- Optimize click-through on internal pages: NavBoost click data influences which pages appear as sitelinks. Pages that users frequently click from the SERP or from your homepage gain sitelink priority. Monitor Search Console for which pages appear as sitelinks and improve underperforming ones
- Avoid duplicate or thin sitelink candidates: If multiple pages serve the same purpose (e.g., /about and /about-us), Google may show neither or alternate unpredictably. Consolidate similar pages so the sitelink algorithm has clear winners for each navigational intent

### Calculations
- Visual Location Sitelink Score: Each hyperlink on the candidate page is rendered to determine its visual location in the page layout. The page is divided into scoring zones: primary navigation (top, above-fold) receives the highest weight, sidebar navigation receives moderate weight, and footer/below-fold links receive the lowest weight. The visual location score is combined with anchor text relevance and click popularity to produce a composite sitelink candidacy score. Affects: Affected by: hyperlink position in rendered DOM, anchor text descriptiveness, NavBoost click-through data on target page, page rendering fidelity.
- Sitelink Trigger Classification: SuperRoot evaluates the query classification to determine whether sitelinks should be generated. Navigational queries (brand searches, known-site queries) trigger full sitelink generation. Informational queries may trigger compact sitelinks only if a dominant authoritative site exists. The trigger threshold depends on query-document match confidence, site authority signals, and historical sitelink click-through rates for the query. Affects: Affected by: query intent classification (navigational vs informational), brand recognition strength, site authority, query-document match confidence, historical CTR on sitelinks for this query.
- Sitelink Click Feedback Loop: Once sitelinks are displayed, user clicks on individual sitelink entries feed back into NavBoost as click signals for those internal pages. Pages that receive high click-through as sitelinks get reinforced in future sitelink selections. Pages that are shown as sitelinks but rarely clicked are gradually deprioritized. This creates a self-reinforcing cycle where popular sitelinks become more prominent over time. Affects: Affected by: sitelink click-through rate, NavBoost 13-month data window, impression count, competing sitelink candidates from same site.

### Sitelink Generation Pipeline
- Query Classification: Query enters the system and is classified by intent. Navigational and brand queries are flagged for potential sitelink generation. SuperRoot checks the classification before activating the sitelink feature backend.
- Top Result Identification: Organic ranking identifies the top result for the query. For sitelinks to trigger, the top result must be a strong navigational match (high confidence that this is the user's intended destination).
- Candidate Link Extraction: The system fetches the top result's page and identifies all hyperlinks. Internal links to the same domain are extracted as sitelink candidates. External links and self-referential links are filtered out.
- Visual Location Scoring: Each candidate link is scored by its visual location in the rendered page (US9053177). Links in primary navigation areas (top nav, above-fold) receive higher scores. Footer, sidebar, and hidden links receive lower scores.
- Click Popularity Overlay: NavBoost click data for each candidate page is overlaid on the visual location score. Pages with strong click histories (high goodClicks, low badClicks) are boosted. Pages with no click data rely solely on structural signals.
- Sitelink Selection and Ranking: Top-N candidates by composite score are selected as the sitelink set. Full sitelinks show 4-6 links; compact sitelinks show 2-4. Duplicate or near-duplicate targets are deduplicated.
- Tangram Assembly: Tangram assembles the sitelinks as a SERP feature block beneath the main organic result. The sitelink feature is composed independently from the organic listing and inserted into the final SERP layout by SuperRoot.

### Timeline
- 2005 (event): Sitelinks First Appear - Google begins displaying sitelinks beneath top results for navigational queries. Initial selection based on PageRank of internal pages and site structure analysis.
- 2011 (event): Expanded Sitelinks Format - Google expands sitelinks from simple text links to rich format with descriptions. Up to 12 sitelinks displayed for strong navigational matches.
- 2013 (patent): Visual Location Patent Filed (US9053177) - Minkoo Seo (Google) files patent for sitelink selection based on visual location of hyperlinks within the page DOM. Introduces rendering-based link scoring where above-fold navigation links are prioritized over footer and sidebar links.
- 2016 (event): Sitelink Search Box - Google introduces the sitelink search box, allowing users to search within a specific site directly from the SERP. Only available for sites with strong navigational authority and proper structured data markup.
- 2022 (event): Sitelinks Redesigned to Compact Format - Google replaces expanded sitelinks with a compact, pill-style format showing 4-6 links without descriptions. Reduces SERP real estate but retains navigational utility.
- 2024 (doj): Tangram/SuperRoot Architecture Confirmed - DOJ trial evidence confirms the Tangram feature assembly and SuperRoot orchestration architecture. Sitelinks identified as one of many SERP features composed by this system, with click data feedback loops via NavBoost.

### Contradictions
- Public (Google Search Console Help): Google automatically generates sitelinks from your site structure. You can help by using clear site hierarchy and internal linking. vs Internal (Patent US9053177 + API Leak (SiteLinkIn, siteLinkDistance)): Sitelinks are selected using a multi-signal scoring system including visual location on page, link authority (SiteLinkIn), click distance from homepage (siteLinkDistance), and NavBoost click data. The Search Console sitelink demotion tool was removed in 2016, eliminating webmaster control.

### Overview
Sitelinks are the indented sub-links displayed beneath a main search result for navigational and brand queries. Assembled by Tangram as a SERP feature and orchestrated by SuperRoot, sitelinks are generated from internal site links scored by visual location, anchor text relevance, click popularity, and site structure. Patent US9053177 reveals that Google scores hyperlinks based on their visual position within the page DOM, not just their anchor text or PageRank. Sitelinks serve as Google's navigational shortcut layer, letting users bypass the homepage and reach deep pages directly from the SERP.
