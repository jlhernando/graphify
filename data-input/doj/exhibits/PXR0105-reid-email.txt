What is "Search grounding"?
•
It allows the Gemini model to check Search results before generating an answer. Doing so increases
accuracy of the moders response (link)
In other words: Gemini model treats Google Search like a corpus for Retrieval-Assisted Generation
•
(RAG)
•
It is enabled for Gemini version offered by Google Cloud over an API as part of Vertex Al
•
This follows on Public Preview launched at Google Cloud Next on 4/9
